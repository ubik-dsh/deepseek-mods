# Compare Renders

**Зачем.** Ворота считают числа, глаза видят «вроде нормально», а **правка вёрстки обнаруживается
только сравнением с прежней версией.** Без этого нельзя ответить на вопрос «я ничего не сломал?» —
можно только верить себе.

```bash
python scripts/render_and_diff.py старое.pdf новое.pdf --out различия
python scripts/render_and_diff.py папка-до папка-после --out различия
python scripts/render_and_diff.py старое.pptx новое.pptx --out различия   # отрендерит сам
python scripts/test-render-and-diff.py                                     # проверка инструмента
```

**Выход:** по странице на строку — сколько процентов пикселей изменилось, и вердикт. Ненулевой код
возврата, если хоть одна страница изменилась больше порога (`--threshold`, по умолчанию 0.5 %).
Рядом кладутся картинки различий: **изменённое подсвечено**, остальное приглушено.

## Откуда приём

У плагина `documents` Кодекса-десктопа есть `scripts/render_and_diff.py` — «render + per-page image
diff between two DOCXs», и в самом скилле записано: **«every meaningful edit batch must end with a
render + PNG review. No exceptions»**. Мы умели рендерить (`--render` в `check-a-deck` и
`check-a-sheet`), но **не умели сравнивать** — и это была единственная дыра, которую ворота не
закрывают: ворота ловят поломки, а не перемены.

**Их скрипт не взят:** лицензия Proprietary. Взята задача; сделан свой на `pymupdf`.

## Что он ловит и чего не ловит

**Ловит:** сдвиг блока, наложение, уехавшую строку, пропавший абзац, изменившийся перенос,
поехавшую таблицу. Всё, что видно на странице.

**Не ловит:** то, чего на странице не было и раньше, — ошибку смысла, неверное число, опечатку,
которую автор и хотел. **Изменение и порча — разные вещи**, и различает их человек: инструмент
показывает, где изменилось, и **не говорит, хорошо ли это.**

**Порог — это про шум.** Антиалиасинг и другой рендерер дают единицы процентов «изменений» на
идентичной странице. Потому сравнение делается только между **одним и тем же рендерером**:
PDF против PDF, PNG против PNG. Сравнивать PNG из LibreOffice с PNG из Word бессмысленно.

## Готово, когда

**Не «сделал», а «вот это сходится»:**

- прогон идёт **в этом сообщении**, а не «я это проверял раньше»: прошлый прогон не довод;
- названо, **чем** проверено, и приведён вывод, а не пересказ вывода;
- если проверка не проходила — так и сказано, с числами, а не «почти»;
- **чего не проверял — сказано прямо.** Молчание о непроверенном читается как «проверено».

## Если заклинило

**Первая ошибка:** прочитать текст ошибки целиком, а не первую строку. **Править малое, а не
переписывать целое:** переписанное заново ломает то, что уже работало.

**Вторая попытка с тем же отказом — стоп.** Однотипный отказ не лечится третьей попыткой;
менять надо не усилие, а подход: другой инструмент, другой разрез задачи, вопрос человеку.

**И признак, что пора остановиться:** если правка делается «чтобы тест замолчал» — это уже не
починка, а подгонка. Тест, который перестал падать сам, ничего не доказал.
