# Говорилка: русская читалка ответов вслух для DSH

**Язык этого документа русский нарочно.** Говорилка говорит по-русски: голос Silero русский,
числа читаются русскими словами, названия файлов и аббревиатуры переводятся русскими буквами.
Если вам нужен другой язык — берите не этот документ, а [`SKILL.md`](SKILL.md): там описан
способ собрать такую же читалку для своего языка и своей модели.

Это то, что читает ответы агента вслух **по мере печати**: первое слово звучит примерно через
секунду после начала ответа, а не после его конца.

## Что внутри

| файл | что делает |
|---|---|
| `../lib/index.js` | мод для DSH: читает живой поток ответа, режет его на куски, говорит подводки, объявляет паузы, держит кнопку в панели |
| `../lib/client.js` | кнопка «Голос: вкл / выкл» в шапке чата |
| `say_stream.py` | тёплый процесс голоса: модель загружена один раз, куски играются очередью, синтез следующего идёт во время звучания предыдущего |
| `speak.py` | сам синтез: Silero, голос `xenia`, ускорение 10% |
| `числа.py` | подготовка текста: числа, даты, годы, версии, единицы |
| `латиница.py` | латиница: имена файлов, расширения, аббревиатуры, английские слова |
| `алиасы-речи.txt` | словарь произношения, который правит человек |
| `получить-голос.py` | достать модель голоса |
| `сказать.py` | проверить голос и произношение без DSH |

## Что нужно на машине

1. **Windows, Linux или macOS.** Разное только воспроизведение звука, синтез одинаков везде.
   - **Windows:** `winsound`, ничего доставлять не нужно, играет в устройство по умолчанию.
   - **Linux:** нужен один проигрыватель: `aplay` (пакет `alsa-utils`), `paplay`
     (`pulseaudio-utils`), `ffplay` или `mpv`. Какой нашёлся, видно в журнале голосового процесса;
     если не нашлось ни одного, чтение вслух откажет с подсказкой, а харнесс продолжит работать.
   - **macOS:** `afplay`, он входит в систему.
2. **Python 3.11 или новее** с `torch` и `numpy`. Тот же питон, которым пользуется DSH, годится.
   **Имя зависит от системы:** в Ubuntu и Debian команды `python` нет, там `python3`. Плагин ищет
   подходящий сам (`python` на Windows, `python3` на Linux и macOS) и называет найденный в журнале;
   можно задать свой переменной `DSH_VOICE_PYTHON`.
   Проверка: `python3 -c "import torch, numpy; print(torch.__version__, numpy.__version__)"`
   (на Linux) или то же с `python` на Windows.
3. **Node 20+** и работающий **DSH** (`dsh web`).
4. **Модель голоса** `v3_ru.pt`, около 59 МБ (шаг 3).
5. Место: около 3 ГБ на `torch`, если его ещё нет.
6. **Ударения (необязательно, но включено).** Русский голос ставит ударение сам и на омонимах
   ошибается: «за́мок» и «замо́к», «сто́ит» и «стои́т». Если поставить пакет `ruaccent`
   (`pip install ruaccent`), читалка расставит ударения сама пометкой `+` перед ударной гласной,
   а голос эту пометку понимает. Проверено замером: пометка на втором слоге меняет форму звука,
   на первом не меняет ничего, потому что там ударение и так по умолчанию.
   Дальше настраивать нечего: ударения включены по умолчанию, модель берётся та, которую ruaccent
   считает своей основной, и грузится в фоне десятки секунд, поэтому первые фразы звучат без
   пометок, а следующие с ними.
   Без `ruaccent` всё работает как раньше: текст уходит как есть. Выключить: `DSH_VOICE_STRESS=0`
   или `stress: false` в строке загрузчика.
   **Про точность, по замеру на списке из восемнадцати пар омонимов:** основная модель дала 12
   верных ударений, облегчённая `tiny` — 11. Ключа `big` в этой версии нет вовсе (проверено:
   `KeyError` по её собственной карте моделей), поэтому «поставить большую» нельзя. Пары, про
   которые спрашивают чаще всего, — «за́мок» и «замо́к», «сто́ит» и «стои́т» — расставляются верно
   любой из них. Точнее модели работает словарь: запись из нескольких слов в `алиасы-речи.txt`
   применяется раньше всех правил, поэтому «Он облился потом» можно закрепить как «облился по+том».
   Вернуть лёгкую модель для экономии памяти: `DSH_VOICE_ACCENT_SIZE=tiny`.

## Установка по шагам

**Все команды запускаются из корня клонированного репозитория**, кроме тех шагов, где явно
сказано перейти в `runtime`.

### 1. Взять код

```powershell
git clone https://github.com/ubik-dsh/deepseek-mods.git
cd deepseek-mods
```

Зеркало на GitVerse, если GitHub недоступен: `https://gitverse.ru/ubikon/dsh-mods.git`.

### 2. Поставить мод в DSH

```powershell
node tools\install.mjs
```

Установщик копирует пакет целиком (вместе с папкой `runtime`) в
`%USERPROFILE%\.dsh\profiles\node_modules\@local\dsh-voice-stream\` и добавляет строку
загрузчика в `%USERPROFILE%\.dsh\profiles\web\cordis.patch.yml`.

**Он ставит не только читалку, а все пакеты этого репозитория** (их девять: менеджер модов,
русский язык, скиллы, распознаватель речи и другие). Если нужна только читалка, ставьте её
вручную: скопируйте `packages\voice-stream` в ту же папку `node_modules\@local\` и добавьте
строку загрузчика сами.

**Помните, что установка ЗАМЕНЯЕТ каталог пакета целиком.** Скачанная модель голоса и ваши
правки в `runtime\алиасы-речи.txt` при повторной установке пропадут; как это обойти, написано
в шаге 3 и в разделе «Обновление».

### 3. Положить модель голоса

```powershell
cd "$env:USERPROFILE\.dsh\profiles\node_modules\@local\dsh-voice-stream\runtime"
python получить-голос.py
```

Скрипт пробует три пути: официальный `torch.hub` Silero, прямая ссылка
`https://models.silero.ai/models/tts/ru/v3_ru.pt` и, если сеть не пускает, советует скопировать
файл руками. **Третий путь не зависит от сети и потому работает там, где скачивание не проходит:**
возьмите `v3_ru.pt` с машины, где читалка уже говорит, и положите в `runtime\voices\silero\`.

Скрипт не верит размеру файла: в конце он **синтезирует фразу и проигрывает её**.

**Чтобы модель пережила обновление, держите её вне пакета.** Установщик мода заменяет каталог
пакета целиком, поэтому модель и правки словаря при следующей установке пропадут. Вылечить это
можно двумя переменными окружения (задайте их перед запуском `dsh web`, например через
`setx`):

```powershell
setx DSH_VOICE_MODEL   "%USERPROFILE%\.dsh\voice\v3_ru.pt"      # модель голоса живёт здесь
setx DSH_VOICE_ALIASES "%USERPROFILE%\.dsh\voice\алиасы-речи.txt" # и словарь тоже
```

Переменные не обязательны: без них всё работает как раньше, модель ищется в пакете.

**Разработчику этого репозитория, отдельно.** После того как модель положена, `node tools\dev\check-deployed.mjs`
покажет расхождение: `only in deployment: runtime\voices\silero\v3_ru.pt`. **Это ожидаемо и правильно:**
модель по замыслу живёт на машине пользователя, а не в репозитории. Чинить это удалением модели
нельзя: без неё говорилка молчит.

### 4. Настроить строку загрузчика

**Установщик уже вписал строку без настроек.** Он добавляет её в
`%USERPROFILE%\.dsh\profiles\web\cordis.patch.yml` как

```yaml
- insert:
    - id: voice-stream
      name: '@local/dsh-voice-stream'
```

**Настройки дописываются в ЭТУ ЖЕ строку, а не второй такой же.** Второй элемент с тем же
`id: voice-stream` создаст две строки одного мода, и та, что без путей, бросит при запуске
`voice-stream: set \`pythonPath\` in the loader row`. Откройте файл, найдите свою строку и
приведите её к виду (путь к питону подставьте свой):

```yaml
- insert:
    - id: voice-stream
      name: '@local/dsh-voice-stream'
      config:
        pythonPath: 'C:\Users\<вы>\AppData\Local\Programs\Python\Python312\python.exe'
        streamPath: 'C:\Users\<вы>\.dsh\profiles\node_modules\@local\dsh-voice-stream\runtime\say_stream.py'
        firstChunk: 50
        chunkChars: 260
        maxChars: 6000
        fillers: true
```

Обязательны только первые два: `pythonPath` и `streamPath`, и оба **абсолютные и существующие**
(иначе мод откажется активироваться). Питон берите тот, у которого есть и `torch`, и `numpy`:
если на машине их несколько, это не обязательно тот, что первым в `PATH`. Остальные ключи это
размеры кусков и подводки, значения по умолчанию подходят.

Перед правкой сделайте копию файла: `Copy-Item cordis.patch.yml "cordis.patch.yml.bak-$(Get-Date -f yyyyMMdd-HHmm)"`.

### 5. Поставить нормализатор текста (очень желательно)

**В тот же питон, который стоит в `pythonPath`**, иначе модуль окажется в другом интерпретаторе
и читалка его не увидит:

```powershell
& "C:\Users\<вы>\AppData\Local\Programs\Python\Python312\python.exe" -m pip install ru-normalizr
```

Если проверка из шага «Что нужно на машине» ругалась на `numpy`, поставьте и его тем же способом:
`& "<путь к питону>" -m pip install numpy`.

Без нормализатора читалка работает, но числа, даты и годы читаются проще (своими правилами из
`числа.py`). С ним: `2026 год` → «две тысячи двадцать шестой год», `voice` → «войс».

### 6. Перезапустить DSH и проверить

```powershell
npx @deepseek-ai/dsh web
```

**Перезапуск обязателен:** новый пакет в уже запущенный харнесс не попадает. **Перезапускает
оператор, а не агент:** перезапуск обрывает его текущий сеанс, поэтому агент только подсказывает
команду и ждёт согласия. Если `dsh web` запущен не из окна терминала, причину отказа мод ищите
в его журнале: строка вида `1 entry did not activate` и следующая за ней строка с ошибкой.

**Осторожно с обновлением мода.** Обновление страницы (F5) подтягивает новую **браузерную**
половину сразу, а **хост** живёт в запущенном процессе и обновляется только перезапуском. Поэтому
после обновления кнопка в панели может появиться и быть неактивной: она это замечает и пишет
рядом «нужен перезапуск dsh web». Это не поломка, а признак старой сборки хоста в памяти.

Проверки по порядку, каждая запуском:

```powershell
cd "$env:USERPROFILE\.dsh\profiles\node_modules\@local\dsh-voice-stream\runtime"
python сказать.py                 # три фразы вслух: числа, латиница, имя файла
python числа.py --selftest        # 17 проверок подготовки текста
python латиница.py --selftest     # 11 проверок латиницы
```

Потом в браузере: в шапке чата должна появиться кнопка **«Голос: вкл»**, а ответ агента —
зазвучать примерно через секунду после начала. Если кнопки нет, смотрите шаг 6 и раздел
«Если не работает».

## Обновление: что при этом теряется

**Каталог пакета установщик заменяет целиком, но данные пользователя он сохраняет.** Пакет
объявляет их в своём `package.json` (поле `dsh.preserve`), и установщик перед заменой копирует их
в сторону, а после замены возвращает на место:

- `runtime\voices\` вместе со скачанной моделью голоса и заготовками подводок;
- `runtime\алиасы-речи.txt` вместе с вашими правками произношения;
- `runtime\ГОЛОС.txt` вместе с положением переключателя голоса.

Установщик об этом скажет строкой `сохранены данные пользователя в @local/dsh-voice-stream: ...`.
Если обновление приносит свою версию того же файла, выигрывает свежая: сохранённое возвращается
только там, где нового файла нет, поэтому старьё не затирает обновление.

Пути к питону и к процессу в `cordis.patch.yml` обновление **не трогает**: установщик строку
дописывает, но существующую с тем же `id` не переписывает. Проверить, что после обновления всё
на месте: `python сказать.py` говорит фразу, а в браузере в шапке чата есть кнопка голоса.

**Модель можно держать и совсем вне пакета** переменной `DSH_VOICE_MODEL` (шаг 3): так удобнее,
если пакет обновляется часто или если одна модель нужна нескольким установкам.

Проверка перед обновлением: `node tools\dev\check-deployed.mjs` показывает, совпадает ли
развёрнутое с репозиторием. Файлы из `dsh.preserve` он расхождением не считает и говорит об этом
словами, чтобы никто не удалил модель ради зелёной проверки.

## Как этим пользоваться

- **Кнопка «Голос: вкл / выкл»** в шапке чата. Она пишет файл `runtime\ГОЛОС.txt`; тот же файл
  читает голосовой процесс, поэтому состояние одно и то же везде.
- **Кнопка «Повторить»** рядом с ней читает заново **последний ответ**. Это для случая, когда
  ответ прозвучал, пока вас не было: иначе повторить чтение нечем. Если повторять нечего (в этой
  сессии ответа ещё не было), кнопка неактивна и объясняет это в подсказке. Повтор идёт тем же
  путём, что и живое чтение, поэтому звучит так же.
- **Подводки.** Короткие фразы («так», «смотрю», «работаю, подожди») заготовлены при запуске и
  звучат мгновенно, закрывая тишину, пока идут инструменты. Больше четырёх за ход не говорятся.
- **Объявления паузы.** Если в команде есть `Start-Sleep -Seconds 59`, читалка скажет
  «Подождём 59 секунд» **до** начала ожидания. До минуты в секундах, больше — в минутах.
- **Словарь произношения** — `runtime\алиасы-речи.txt`, строки вида `BIOS = биос`. Файл главнее
  любых встроенных правил: что написано там, так и прозвучит.
- **Послушать варианты слова:** `python сказать.py --варианты nvme`.

## Если не работает

| что видно | в чём дело | что делать |
|---|---|---|
| Кнопки нет, голос молчит | плагин не поднялся | посмотрите консоль `dsh web`: там будет `1 entry did not activate` и причина. Частая: забыт `inject: ['connection']` в `lib\index.js` |
| `cannot get property "connection" without inject` | харнесс не отдаёт службу, которую мод не объявил | в `lib\index.js` должно быть `export const inject = ['connection']` |
| Звука нет, файлы синтеза есть | играется в устройство по умолчанию | проверьте устройство воспроизведения Windows; `winsound` играет только в него |
| Первое слово ждать 7–9 секунд | грузится модель голоса | это один раз при старте процесса; дальше процесс тёплый 10 минут простоя |
| Числа пропали из речи | не читается цифрами | поставьте `ru-normalizr` (шаг 5) и перезапустите `dsh web` |
| Слово звучит криво | голос не знает слова | допишите строку в `алиасы-речи.txt`, перезапуск не нужен |
| Речь обрывается на середине ответа | сработал предохранитель `maxChars` | поднимите `maxChars` в строке загрузчика |

## Чего здесь нет и почему

- **Распознавания речи** (микрофон, «слушалка») здесь нет: это отдельный мод
  `@local/dsh-speech-ru-gigaam` в том же репозитории. Читалка и слушалка независимы.
- **Модели голоса в репозитории нет**: 59 МБ бинарника в git не кладут, его берут шагом 3.
- **Никаких секретов, ключей и токенов** в пакете нет: настройки и путь к питону живут в
  строке загрузчика на вашей машине, а не в коде.
