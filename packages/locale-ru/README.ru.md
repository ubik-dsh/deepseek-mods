# @local/dsh-locale-ru

**Русская локализация** Web-GUI харнесса. Штатный харнесс поставляет только английский и
китайский; этот плагин добавляет третий язык через публичный API языковых
пакетов реестра локали.

*English version: [README.md](README.md).*

![Выбор языка: Русский](../../docs/screenshots/russian-settings.png)

## Покрытие

| Метрика | Значение |
|---|---|
| Пространств имён | 42 |
| Строк переведено | 1257 |
| Из них с кириллицей | 1195 |
| Размер бандла | ~88 КиБ |

Остальные ~60 значений намеренно не переводятся: `OK`, `HTML`, `PDF`, `JSON`,
идентификаторы моделей, имена приложений и строки, состоящие только из
плейсхолдеров (`{name}`, `{value}K`).

## Как это работает

```js
ctx.locale.addLanguage({ id: 'ru', label: 'Русский', fallback: 'en' })
ctx.locale.register(namespace, 'ru', dictionary)
```

Цепочка отката ведёт в `en`, поэтому пространство имён или ключ без перевода
показывается по-английски: пакет деградирует построчно, а не ломает интерфейс.

## Как выбрать язык

**Настройки → Общие → Язык → Русский.** Переключение мгновенное, без
перезагрузки; выбор сохраняется в `$DSH_HOME/settings.yaml`.

Браузер, который просит русский (`Accept-Language: ru`), получает русский
интерфейс сразу: харнесс берёт локаль из браузера, пока не сохранён явный выбор.

## Как править переводы

`lib/client.js` — **сгенерированный** файл. Правь исходники и пересобирай:

```
i18n/en/<пространство>.json    английский оригинал, извлечённый из установки харнесса
i18n/ru/<пространство>.json    русский перевод
```

```bash
node tools/build-locale.mjs
```

Сборщик откажется писать бандл, если набор ключей или набор плейсхолдеров в
переводе расходится с английским оригиналом, а также при пустых значениях —
поэтому опечатка не уедет молча.

## Обновление под новую версию харнесса

```bash
node tools/extract-locale.mjs     # перечитать штатные словари
node tools/build-locale.mjs       # пересобрать, сохранив готовые переводы
```

Новые пространства имён и ключи появляются на английском, пока их не переведут
в `i18n/ru/`.

## Проверка

```bash
node tools/dev/test-locale-ru.mjs   # контракт плагина и полное покрытие ключей
```

## Ограничения

- Харнесс не предоставляет языковым пакетам правил множественного числа, поэтому
  формы выбраны под категории `.one`/`.other`, между которыми выбирает
  интерфейс.
- Текст, который плагины читают один раз при регистрации (описания слэш-команд и
  подобное), сохраняет язык регистрации до перезагрузки страницы — это
  ограничение харнесса, а не пакета.
- Пространство имён `directory-browser` (13 строк) переведено вручную: его
  словарь регистрируется в цикле, и автоматический извлекатель его не видит.
