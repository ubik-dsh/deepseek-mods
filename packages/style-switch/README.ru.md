# style-switch

Кнопка в шапке чата: **как думать над следующим сообщением**.

| Стиль | Что добавляет в системный промпт |
|---|---|
| **DSH** | **Ничего.** Раздел промпта не регистрируется вовсе, поэтому промпт — ровно тот, что отдаёт харнесс. |
| **КОДЕКС** | Краткий стиль: сначала ответ, потом короткое доказательство; ветви случаев вместо полного перебора; ничего сверх вопроса; таблица или 5–10 строк. |

**Откуда взялось.** Одна и та же задача-ловушка, одна и та же модель DeepSeek, два харнеса:
у нас 7 мин 24 с и 306K токенов, у Кодекса-десктопа 2 мин 14 с. **Оба ответа верные.**
Разница была в объёме работы, а не в качестве мысли — поэтому объём теперь выбирается
кнопкой, а не решается промптом за пользователя.

**Стиль `DSH` нарочно пустой.** «Повторить умолчание» нельзя сделать текстом, который
«ничего не меняет»: это делается тем, что стиль не добавляет ничего, и промпт остаётся
побайтово штатным.

## Из чего состоит

```
packages/style-switch/
  package.json
  lib/index.js     host-половина    — раздел промпта и роут /api
  lib/client.js    браузерная половина — контрол в шапке и окно выбора
```

- **Хост** регистрирует раздел системного промпта, текст которого перечитывается при каждой
  сборке, — поэтому переключение доезжает до следующего запроса без перезапуска. Раздел
  существует только пока выбранный стиль что-то добавляет.
- **Хост** же владеет `GET`/`POST /api/style-switch.mod` на том аутентифицированном канале
  Connection, на котором уже говорит веб-интерфейс.
- **Браузер** регистрирует один контрол в `conversation.session.header.utilities` и
  показывает каждый стиль карточкой — вместе с текстом, который этот стиль добавит.

Состояние лежит в `$DSH_HOME/style-switch.json`. Нечитаемое или неизвестное значение
откатывается к `dsh`: испорченный файл стоит настройки, а не интерфейса.

## Установка

```bash
node tools/install.mjs            # из корня репозитория
node tools/boot-check.mjs         # попал ли пакет в отдаваемый boot-граф
```

Текст раздела живой, но **изменённый файл пакета требует перезапуска `dsh web`** — загрузчик
импортирует модуль один раз на процесс.

## Проверка

```bash
node tools/dev/test-style-switch.mjs          # host-половина, с поддельным ctx
node tools/dev/test-style-switch-client.mjs   # браузерный бандл, с заглушкой загрузчика
```
